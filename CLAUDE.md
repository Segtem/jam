# Jam

Las instrucciones del proyecto están en **[`AGENTS.md`](AGENTS.md)** — un solo archivo para los dos
agentes que se turnan Jam, para que no se separen en silencio.

Para retomar: `oracle tarea listar` y `oracle tarea ver <id>`. Dejá avances y el próximo paso
en esa tarea, siguiendo el protocolo de `AGENTS.md`; no escribas otro relevo suelto.
