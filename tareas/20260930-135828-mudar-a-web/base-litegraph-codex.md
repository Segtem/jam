## Consecuencias del conversor actual

`aJam` (JS:167) construye un documento nuevo sólo con schema_version/nodes/edges; no conserva campos desconocidos. `desdeJam` (JS:194) limpia antes de comprobar todos los nodos. Por lectura del código, el viaje abrir → guardar pierde:

- `comments`, `reroutes`, `nodes[*].compact`, `nodes[*].debug`; los dos últimos no son intercambiables: debug influye en el recorte/visualización de ejecución (graph.py:776), compact es vista.
- Parámetros que no tengan widget, o campos de futuras versiones; un verbo desconocido se omite en vez de conservar un placeholder o rechazar el documento completo.
- Cables antiguos de dos elementos: desdeJam desestructura siempre cuatro (JS:219); JamGraph soporta ambos formatos (graph.py:145).
- Expresiones numéricas: el widget number carga mediante Number(v) (JS:211); una expresión canónica no es un número JS. El combo también hace String(v), no valida identidad/etiqueta.
- Posiciones exactas: aJam redondea y desdeJam llama separarEncimados siempre. Cargar un documento ya acomodado puede moverlo.

Además, pegar/clonar conserva el nombre Jam porque el identificador interno LiteGraph es otro. Esta colisión se deduce directamente de LG:7339 + JS:106 + JS:175; no se ejerció el gesto en navegador en esta revisión.

Antes de agregar paneles, usar un documento Jam completo como fuente de verdad y un adaptador de vista sin pérdida. El JSON LiteGraph debe quedar como detalle de renderer. Conservar grupos, vías, flags, campos y nombres estables al abrir/guardar, copiar/pegar, aplicar texto y editar funciones.

## Delimitación de lo que no viene dado por la biblioteca

Live view, estados del oráculo, display/debug flag, inspección de datos, miniaturas, biblioteca de funciones, presets, assets y captura de la mira son producto Jam. Ninguna biblioteca de nodos reemplaza esos contratos. `grafo.start()` (JS:405) es el bucle de ejecución LiteGraph: no es el Run/Live view de Jam, que llama Python (JS:362). La base recomendada debe renderizar sin introducir un segundo evaluador del DSL.
